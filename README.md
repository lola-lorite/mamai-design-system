# MamAI

A small tool for a new mother whose days never repeat — built by a product
designer learning to work the way product teams are starting to work: specs and
design systems kept as files, agents building from them, a human judging the result.

**Status:** week 0. Nothing is built yet.

## Why this repo looks like this

The designer's deliverable is moving away from the mockup and toward the **spec** —
a plain text file, kept next to the code, that says what to build, why, how you'd
know it worked, and what was deliberately rejected. So the thinking lives here, in
markdown, versioned, where both a person and an agent can read it.

## The eight weeks

Git & GitHub → spec-driven design → design tokens → agent instructions →
MCP & agent skills → deploying → AI-ready design systems → packaging it up.

Each week: 1 hour learning, 3 hours building, 1 hour writing it down.
Friday afternoon, one thing that proves the week happened.
