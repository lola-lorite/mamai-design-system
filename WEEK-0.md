## The six words of git — that's the whole course

| Word | What it actually means |
|---|---|
| commit | Save a version, with a note about what you changed |
| push | Send your saved versions up to GitHub |
| branch | Try something without breaking the good version |
| pull request | Propose that your branch becomes the real version |
| merge | Accept it |
| revert | Undo a commit you regret |

That is it. Six words, and the rest is practice.
